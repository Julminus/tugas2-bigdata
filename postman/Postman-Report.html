Collection: Tugas 2 - Taxi Fare Model API (Databricks Model Serving)
Collection Description
Health check + inference tests for the Databricks Model Serving endpoint that serves the best MLflow model (workspace.tugas2.taxi_fare_model@champion). Set collection variables `host`, `endpoint_name`, and `token` (a Databricks personal access token - keep it in the Postman *current value* only, never commit it). Input schema (from silver_taxi): trip_distance (mi), trip_duration_min, pickup_hour (0-23), pickup_dow (1=Sun..7=Sat), pickup_zip, dropoff_zip. Output: predicted fare_amount (USD). Requests 4-5 connect the Google Drive dataset to the API: request 4 downloads My Drive/tugas2/nyctaxi_trips.csv (public link, no auth - the Databricks token is NOT sent to Google), validates it and builds features for `gdrive_sample_size` evenly spaced trips exactly like silver_taxi (duration in minutes rounded to 2 decimals, hour, dayofweek 1=Sun..7=Sat, missing zip -> 0, silver expectations applied). Request 5 sends those trips to the model and compares predictions with the real fare_amount. Note: these trips come from the same source the model was trained on, so the error shown is an in-sample sanity check, not a held-out evaluation.
